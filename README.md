# Tether

A small social app where you can post, like, and follow people. It runs in the browser as a single page.

## Features

- Join with a name
- Write posts (up to 280 characters)
- Like and unlike posts
- Follow people and switch between the Everyone and Following feeds
- Works on phones and desktops, with light and dark modes

## How to run it

1. Download `tether.html`.
2. Open it in any web browser.

No install or setup needed.

## Hosting it for free

1. In this repository, go to **Settings** and then **Pages**.
2. Under **Branch**, choose `main` and save.
3. After a minute, GitHub shows your live link.

For this to work, rename `tether.html` to `index.html`.

## Current limits

Posts, likes, and follows are saved only in your own browser, so other people can't see them yet.
